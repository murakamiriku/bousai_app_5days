# 防災アプリの検索画面・検索機能・選択機能・ハンバーガーメニューを実装するための一括プロンプト

以下の要件を満たすように、Flask + Jinja2 + HTML/CSS/JavaScript の構成で防災アプリの検索画面を実装してください。

## 目的
- 避難所検索ページを作成し、検索フォーム、絞り込み条件、地区選択チェックボックス、ハンバーガーメニューを実装する。
- 既存のアプリ構造に自然に組み込めるようにし、他の人のシステムにも移しやすい形で実装する。

## 前提
- Python の Flask アプリとして実装する。
- テンプレートは Jinja2 を使う。
- 共通レイアウトは base.html を使用する。
- ルーティングは app.py で管理する。
- 画面の日本語表示を前提とする。

## 実装対象

### 1. ベーステンプレート
- 共通のヘッダー、メニュー、メインコンテンツ領域を持つ base.html を作成・更新する。
- ヘッダー右上にハンバーガーメニュー（☰）ボタンを配置する。
- ボタンは `<button>` 要素で、アクセシビリティを考慮して `aria-label` / `aria-expanded` / `aria-controls` を付ける。
- クリックでメニューを開閉できるようにする。
- メニューはポップアップ風のドロワーとして表示し、背景クリック・×ボタン・Escキーで閉じられるようにする。

### 2. 検索画面
- 避難所検索ページ用のテンプレートを作成または更新する。
- 検索フォームには以下を配置する。
  - テキスト入力欄
  - 検索ボタン
  - 距離フィルター（セレクトボックス）
  - 混雑具合フィルター（セレクトボックス）
  - その他支援条件フィルター（セレクトボックス）
  - 地区選択チェックボックス群
- 検索フォーム周辺に、見た目が整ったカード型の検索ボックスを作る。
- 検索画面は背景に地図風の装飾や淡い青系のヒーローエリアを持たせる。

### 3. UI/UX の改善
- チェックボックスとラベルのセットが横並びで見やすいようにレイアウトする。
- 各項目がタップしやすいよう、十分な高さ・余白・ボタン風の見た目を持たせる。
- チェックボックス自体のサイズも大きめにし、クリックしやすいデザインにする。
- 検索ボックス全体が上に詰まりすぎないよう、上下に余白を持たせて見やすくする。
- 文字が縦書きのように崩れず、チェックボックスとテキストが横方向に揃うようにする。

### 4. JavaScript
- ハンバーガーメニューを開閉する JavaScript を実装する。
- `DOMContentLoaded` 内でイベント登録を行い、読み込み後でも確実に動くようにする。
- メニューの表示/非表示は `.is-open` や `.active` クラスで切り替える。
- メニューリンククリック時には自動で閉じるようにする。
- 背景クリック・×ボタン・Escキーで閉じるようにする。

### 5. Flask ルート
- `/` でトップページを表示する。
- `/shelter_search` で避難所検索ページを表示する。
- `/shelter_register` で避難所登録ページを表示する。
- `/board` で指示・発信ボードを表示する。
- ログイン・ログアウトのルートを実装する。
- ログイン状態に応じてメニュー内の表示を切り替える。

## 実装時の注意点
- 既存の Flask プロジェクトの構成に合わせて、テンプレートは `bousai_app/templates/` 配下に配置する。
- CSS は base.html 内に `<style>` で定義するか、必要なら static/css に切り出す。
- 画面の見た目は日本語 UI に合わせて、落ち着いた青系・白系の配色にする。
- レスポンシブ対応を意識し、スマートフォンでも押しやすいレイアウトにする。
- ユーザーが今後追加しやすいよう、クラス名は分かりやすく命名する。

## 期待する出力
- 実行可能な Flask アプリのコード
- `base.html` にヘッダー・ハンバーガーメニュー・共通スタイルを追加
- `shelter_search.html` に検索フォーム・条件選択・地区チェックボックスを追加
- 必要に応じて `app.py` にルート追加
- 画面がブラウザで確認できる状態
